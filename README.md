# 🔬 Predictive Analysis for Plain Carbon Steel

A machine learning-powered web application that predicts the microstructural and mechanical properties of plain carbon steel based on its chemical composition and heat treatment parameters.

## 📌 Overview

This project combines Machine Learning and Materials Engineering to estimate steel properties without performing expensive laboratory experiments.

Users can input material composition and processing parameters to predict:

- Grain Size (ASTM Number)
- Grain Classification
- Ferrite Percentage
- Pearlite Percentage
- Cementite Percentage
- Yield Strength
- Tensile Strength
- Hardness
- Elongation
